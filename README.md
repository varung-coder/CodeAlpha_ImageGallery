# Image Gallery

## 📖 Overview
A cinematic, premium-quality responsive image gallery web application built as part of the front-end development internship at CodeAlpha. The project features a modern dark UI with glassmorphism aesthetics, an advanced masonry-style layout, category filtering, 3D tilt hover effects, and a smooth fullscreen lightbox experience.

## 🚀 Live Demo
You can view the live project here: https://varung-coder.github.io/CodeAlpha_ImageGallery/

## ✨ Key Features
- **Cinematic Preloader:** A sleek loading animation before revealing the gallery.
- **Masonry-style Grid:** A fully responsive image grid that beautifully handles varying image sizes.
- **Advanced Filtering:** Smooth transition effects when filtering images by categories (Nature, City, Animals, Technology, Travel).
- **Fullscreen Lightbox:** Interactive modal for viewing high-res images with keyboard navigation support and image counters.
- **Micro-interactions:** High-performance 3D card tilt effects, magnetic buttons, and staggered scroll-reveal animations.
- **Responsive Design:** Optimized for seamless viewing on mobile, tablet, and desktop screens.
- **Modern Aesthetic:** Matte black background with gradient glowing blobs and a floating particle system.

## 💻 Tech Stack
- **HTML5:** Semantic structuring and accessible layout.
- **CSS3:** Advanced styling using CSS Variables, Glassmorphism, CSS Columns (for masonry layout), and custom animations.
- **Vanilla JavaScript:** High-performance DOM manipulation, Intersection Observers for scroll reveals, `requestAnimationFrame` for 60FPS hover effects, and filtering logic.
